ホーム 学習の流れ Idea Projects Writing Habits SF6

ホーム

今日やること（ToDo・Habit・着手が必要なProject）と、各ダッシュボードの件数をまとめて見るページです。

Focus
表示は5件までです。5件あるときに追加したFocusは「表示解除中」に入り、「管理」から表示中の1件と入れ替えられます。外したFocusも表示解除中に残ります。
データ管理
Knowledge・Financeのデータを読み取り専用で書き出せます。接続状態のページでは、各サービスへの接続と自動処理の状態を確認できます。

学習の流れ

  1. 戦略：Wantsで学びたいことを選び、Projectsで到達点と次の一手を決めます。「進行中」はActive Projectの件数です。
  2. インプット：Inboxへ疑問や素材を入れて振り分けます。Journalでは過去の日記を読み返せます。「未整理」は処理前のInboxの件数です。
  3. 抽象化・構造化：Knowledgeの「整理」で、示唆を問い・タグ・ノートにまとめ、出典をたどります。Hubでは件数を集計していません。
  4. ストック・取り出し：Knowledgeに保存した内容を検索し、復習します。「今解ける」は期限が来た出題可能な問題数で、保存したナレッジの総数ではありません。

件数を取得できないときは、その旨を表示します。どの段階からでも開けます。Projectのテーマによって復習順や入力候補が自動で変わる仕組みはありません。

Idea

思いつき（Inbox）、やりたいこと（Wants）、予定（ToDo）を管理します。データはSupabaseに保存され、ToDoの予定はGoogle Calendarと同期します。

Inboxの項目は、振り分け先（ToDo・Project・執筆・Knowledgeなど）を選んで整理します。保存や外部への登録の前には、何が起きるかを画面で確認できます。

「AIに整理案を聞く」「AIに振り分け案を聞く」を押したときだけ、本文をClaude APIへ送ります。追加質問に回答すると、その回答も送って案を作り直します。案は未保存です。「この案を使う」で編集画面を開き、内容を直してから保存します。Google Calendarへの登録は、その後の確認画面で確定します。

Knowledgeの示唆・日記から登録した行動には、元の本文と「行動元」のリンクが付きます。リンクから現在の出典を開けます。元の出典が編集・削除されても、登録時の引用はInboxに残ります。

InboxからSF6へ整理する

未整理Inboxの「その他の振り分け先 → SF6」、または手動整理の「SF6へ整理する」から、局面・手順（コンボ／起き攻め）・練習メニューに登録できます。SF6の画面で必要な項目を確認してから保存します。一括振り分けには含めません。

元メモの全文はメモ／やり方へ入り、最初の非空行だけ名前の候補になります。キャラ・有利F・始動・レシピは自分で入力してください。保存するとSF6への登録とInboxの整理済み化が同時に行われます。キャンセルではInboxは未整理のままです。整理済みInboxから登録先を開け、保存先が削除されていれば、その旨を表示します。

ToDoとProjectタスクの紐づけ

ToDo詳細の「Projectタスクと紐づける」から、同じ行動の既存タスクを1件選びます。Project側の「既存ToDoと紐づける」からも操作できます。名前から自動判定せず、1対1で紐づけます。保存前に両方の名前・日時・変更後の状態を確認してください。

紐づいている間、実施状態はToDo、日時はGoogle Calendarに揃います。完了・見送りはProjectタスクにも反映し、Calendar予定を変更しません。Next Actionを終えるときは、次を決める・Project完了・待機・保留を選びます。未実施に戻すとタスクは「あとで行う」に戻り、勝手にNext Actionにはなりません。終了済みProjectの場合は、先に紐づけを解除してください。

解除してもToDo・Projectタスク・Calendar予定は残ります。Projectの日付は紐づけ前に設定していた値に戻ります。Calendarの取消済み予定も、紐づいたToDoは自動削除せず残します。

Projects

進行中
Next Action（次にやる1件）を決めて動かしているProjectです。Active Projectには、作成時からNext Actionを1件設定します。
要確認
次の一手が決まっていない、または整理が必要なProjectです。
待機・保留
再確認日まで待つProjectです。
完了
達成した目標です。

週次レビュー

目標期限を過ぎたProject、期限超過のタスク、要確認、待機・保留の見直し日、14日以上更新がない停滞をまとめます。目標期限は日本時間の今日より前の日付が対象で、今日・未設定・終了済みProjectは含みません。今週完了したタスクは月曜始まりで振り返れます。

「見直し項目」は各欄の項目数の合計です。同じProjectに複数の理由があれば、それぞれに数えます。行を押すとProject詳細を開き、目標日や次の行動を見直せます。

既存ToDoとの紐づけ

各タスクから既存ToDoを1件選んで紐づけられます。完了済み・取り消し済みのタスクも選べますが、新しい紐づけ先のProjectは進行中・待機・保留から選んでください。状態が異なる場合はToDoに揃えます。日程の変更はToDo詳細から行い、Projectの一覧・詳細・週次レビュー・Hubには同じ予定日を表示します。タスクの内容やマイルストンはProjectで編集できます。

おすすめ

目標日が近い順

Writing

本文はPomeraで書き、このページではテーマのアイデア（これから書くテーマ）と完了（書き終えたテーマ）だけを管理します。

テーマはIdeaの項目を「執筆」に振り分けて追加します。このページから直接は作りません。手順はページの「Ideaから追加」で確認できます。

Habits

今日できた
今日、実施の記録をつけたHabitの数です。
今日・今週の残り
今日が対象日でまだ記録していない毎日・平日のHabitと、今週まだ目標回数に届いていない毎週のHabitの数です。休んだ日・休んだ週と、自由頻度のHabitは数えません。
継続中
有効（休止・アーカイブでない）なHabitの数です。

毎週のHabitも1日1回ずつ数えます。回数や頻度を変えると、過去の週も新しい目標で数え直します。

SF6

スト6（クラシック操作）のコンボパーツ・フレーム・練習メニュー・対戦振り返りを記録します。コンボと起き攻めは区別せず、どちらも「コンボパーツ」です。パーツは、始動の状況から始まり、ヒット・ガード・無敵技・バクステ・グラップなどの結果で分岐し、続けられるなら次のパーツへつながります。

Inboxのメモを登録する

Inboxから来たフォームでは、局面・コンボパーツ・練習の登録先を切り替えられます。元メモは保持します。2,000字を超える古いメモも切り捨てず表示するため、補足を編集してから保存してください。元Inboxの原文は残ります。

保存した記録の編集画面から元Inboxを開けます。元Inboxが削除されているときは保存時の原文を確認できます。「SF6への保存は完了しています」と表示された場合は保存先のIDを保持しているので、「表示を再読み込み」で表示だけを再試行できます。同じ操作の再送で記録が増えることはありません。

コンボパーツの追加・編集では、キャラ、名前、始動の状況、レシピ、結果（通常ヒット・カウンターヒット・パニッシュカウンター・ガード・相手の行動ごと）を入力します。「任意項目」を開くと、その他のヒット・発生F・ゲージ消費・位置・重ね方・習得度・メモなどを入力できます。名前が空欄ならレシピから自動で付けます。

始動の状況は、上に選んだ状況が並び、「×」で外せます。確定反撃・ヒット確認などのきっかけは、押すだけで足せます。局面は下の欄に有利F・ダウン・位置を入れるか、一覧から選んで「追加」します。ほかのキャラの局面は出ません。

レシピの入力

コンボを追加するときは、パレットのボタンを押した順にレシピが並びます。方向やコマンド（波動・竜巻・昇龍など）を押してから攻撃ボタンを押すと、1つの技になります（例：↓→中K）。「⌫ 1つ戻す」で最後の部品から消せます。

方向
テンキーの配置です。Nはニュートラル（立ち）です。ジャンプ攻撃は「ジャンプ」を押してから攻撃ボタンを押します。
攻撃
弱・中・強のP（パンチ）とK（キック）です。PP・KKは2つ同時押し（OD技など）です。表示ではPが橙、Kが青で、強いほど色が濃くなります。強さを問わないボタン（SAのコマンドなど）は白い札のP・Kで出ます。
› つなぎ ／ キャンセル
「›」は目押しやラッシュでつなぐ区切り、「キャンセル」は必殺技やSAでキャンセルする区切りです。TCはターゲットコンボです。
DR・DI・パリィ・SA
ドライブラッシュ、ドライブインパクト、ドライブパリィ、スーパーアーツ（SA1〜3）、クリティカルアーツ（CA）です。
よく使う
同じキャラの記録でよく使う出だし（最初の区切りまで）を表示します。押すとまとめて入ります。
文字で直接編集
「ディレイ」などボタンにない言葉は、ここで直接書き足せます。数字（236など）とボタン名（中Pなど）は、そのまま矢印と色付きのボタンで表示されます。

キーボードでレシピを入力

レシピのプレビューをクリックするか、Tabで選ぶか、「⌨ キーボード入力」を押すと入力できます。枠が付いている間だけ有効です。キャラ名・メモ・「文字で直接編集」では通常どおり文字を入力できます。日本語IMEはオフにしてください。

方向：矢印キー / 数字1〜9（テンキーも可）
↑↓←→で方向を入れます。↓と→など、矢印2つの同時押しは斜め1つになります。次の方向へ進むときは矢印を全部離してください。波動なら「↓を押して離す → ↓と→を一緒に押して離す → →を押して離す」、数字なら236です。5はニュートラルです。
攻撃：U / I / O、J / K / L
U・I・Oが弱P・中P・強P、J・K・Lが弱K・中K・強Kです。Shiftを押しながらパンチのキーでPP、キックのキーでKKを入力します。例：236 Oで236強P、2 Kで2中Kになります。
つなぎ・キャンセル：Space / X / C
Spaceはつなぎ（›）、Xはキャンセル、Cはターゲットコンボ（TC）です。
ジャンプ・ドライブ・投げ：Q / R / F / P / T
Qはジャンプ、RはDR、FはDI、Pはパリィ、Tは投げです。
SA・CA：Shift + 1 / 2 / 3 / 4
Shift+1〜3でSA1〜3、Shift+4でCAを入力します。
戻す：Backspace
最後の部品を1つ消します。キーの長押しでは連続入力しません。Tabでレシピ欄を離れるとキー入力は止まります。

状況と手順

コンボパーツは、「状況 → パーツ → 次の状況」で記録し、1つの「パーツ」タブに並びます。状況には2種類あります。

きっかけ
確定反撃・ヒット確認・対空・パニッシュカウンターなど、数値を持たない始動のきっかけです。最初から入っているもの（一覧に「初期」と出るもの）は、確定反撃の並べ替えなどの判定に使うので削除できません。名前の変更とアーカイブはできます。
局面
「強エアニー締め後 +29F 画面端 後ろ受け身可」のように、有利F・位置・ダウンを持つ状況です。新しい局面の名前は、移行時と同じく手順名の最後の語に「締め後」を付けます（「中足ラッシュ 強エアニー」なら「強エアニー締め後」）。手順名が空欄ならレシピの締め技を使い、名前は手で変更できます。同じキャラで有利F・位置・ダウンが同じなら、名前が違っても1つの局面にまとまります。画面端は「相手が画面端」です（自分が背負う局面は、名前で区別してください）。
有利F
トレモのフレームメーターで、相手が起き上がって動けるまでに自分が先に動けるフレーム数を読み、そのまま入力します。ダウンは「後ろ受け身 可／不可／ダウンなし」から選びます。後ろ受け身を取られると画面中央では位置がずれるため、起き攻めが合うかの判断に使います。
局面の入力
「ヒットしたら」などで有利F・ダウンを入れると、同じ局面があれば「既存の〜を使います」と出て、それを使います。なければ新しい局面を作ります。名前の候補はレシピの最後の技（フレームが登録されているキャラ）か、数値です。「一覧から選ぶ」で、このキャラの局面ときっかけからも選べます。
状況タブ
キャラを選ぶと、そのキャラの局面を有利Fの大きい順に一覧できます（「投げ後 +4F 画面中央」「強エアニー締め後 +29F 画面端」など）。位置で絞り込むと、選んだ位置の局面と「どこでも」の局面が出ます。各カードのボタンは、その局面を始動に選んでいるコンボパーツです。有利Fや位置が近い・同じというだけでは、自動ではつながりません。右上の「＋」で局面を足せます。カード右下の「＋パーツ」は、その局面を始動の状況にしたコンボパーツの追加画面を開きます（キャラ・位置も引き継ぎます）。「フロー」は、その局面を始点にしたフローチャートを開きます。局面には「通常投げ間合い」のフラグを付けられ（局面の編集）、カードにタグで出ます。
状況の管理
手順タブの「⋯」→「状況を管理」で、きっかけと局面の一覧と、それぞれを使っている手順の数が見られます。使われている状況を削除するときは、「外して削除」（全部の手順から外す）か「アーカイブにする」（一覧から隠すだけで、手順の記録は残す）を選びます。始動の状況がなくなった手順は、状況の絞り込みの「状況なし」に出ます。使っている手順がある状況は、キャラと種類を変えられません（きっかけを全キャラ共通にすることだけはできます）。

条件

手順タブで状況と条件（残りDゲージ・SAゲージ・相手の不利F・CA可・自分がバーンアウト中）を選ぶと、今使える手順だけが並びます。CAはSAゲージ3本と、体力25%以下（CA可）が必要です。

自分がバーンアウト中
Dゲージ消費が0で、レシピにDR・DI・パリィ（ドライブリバーサルを含む）・OD必殺技（236PP のようにコマンド＋PP・KK）を含まないコンボだけになります。2PP のようなコマンド特殊技やSAは使えます。コンボごとのチェック項目はありません。
相手の不利F
入れると、発生Fがその数以下のコンボだけを、発生の速い順に並べます。発生Fが未入力のコンボは出ません。
並び順
相手の不利Fを入れたときと、確定反撃を選んだときは発生の速い順です。何も選ばないときは登録順です（条件がないときは起点の有利Fが大きい順）。
発生F
パーツの最初の技の発生です。フレームが登録されているキャラでは、レシピの最初の技から「5弱P 発生4F を入れる」のような提案が出ます。押すと入ります。

結果

パーツには、ヒットしたとき・ガードされたとき・相手の行動ごとに、次の状況を付けられます。ヒットは、「通常ヒット」「カウンターヒット」「パニッシュカウンター」「その他のヒット」に分けて次の状況を付けられます。カウンターヒットとパニッシュカウンターは、未設定なら通常ヒットと同じ状況です（別の分岐にはなりません）。別の状況にしたいときだけ入れます。「＋2Fで設定」「＋4Fで設定」を押すと、通常ヒットの有利Fに足した値が入り、以後は通常ヒットを変えるとそれに追従します（手で直すと追従しません）。「通常ヒットと同じにする」で空に戻せます。通常ヒットと同じ状況を入れても、保存のときに分岐にしません。「その他のヒット」は詳細の中にあり、ジャンプを対空で落としたときなど特殊な条件のヒットを、有利F・ダウン・位置・名前を自由に決めて付けます。通常ヒット以外は、入れたときだけカードやフローチャートに出ます。各結果（通常ヒット・ガードなど）の次の状況は、「＋選択肢を足す」で複数持てます。例えばコンボがヒットした後の状況を、画面中央版と画面端版の2つ登録できます（選択肢ごとに有利F・ダウン・位置を決めます）。相手の行動の結果で通常ヒットなどを選ぶと、その結果の選択肢すべてが対象になります。カードやフローでは、選択肢ごとの行・矢印として出ます。カードの「ヒット → 〜 ›」を押すと、ルートが開きます。

相手の行動ごとの結果
無敵技・バクステ・ジャンプ・グラップ・遅らせグラップ・暴れ・ドライブインパクト・パリィ・ドライブリバーサル・後ろ受け身のそれぞれに、○（こちらが勝つ）・×（負ける）・–（未確認）を付けます。○か×にすると「→」が出て、その結果が通常ヒット・カウンターヒット・パニッシュカウンター・その他のどれになるかを選べます。最初の3つは、上の同名のヒットの状況（有利Fは通常ヒットに連動）がそのまま次の状況になります。「その他」を選んだときだけ、有利F・ダウン・位置・名前を個別に決められます（例：グラップ → 投げスカり）。
後ろ受け身
起点に後ろ受け身できるダウンがあるときだけ表示します。トレモの受け身設定を「後ろ受け身」にして確かめます。
続けられるパーツ
ヒットの結果に選んだ状況を、始動に選んでいるパーツだけが出ます。つなぎは必ずあなたが指定したものだけで、有利Fなどから自動ではつなぎません。

ルート

状況のチップや結果の行を押すか、「⋯」→「ルートで見る」で開きます。その状況から使える手順が並び、結果の行を押すと次の状況へ進みます（上の道のりを押すと戻れます）。次の状況を入れていない起き攻めなどは、カードの「この手順で終える」で道のりの最後に入れられます。その状況を始動に選んでいる手順だけが出ます（有利Fが近い局面からの自動的なつなぎはしません）。手順タブの条件（Dゲージ・SA・CA・バーンアウト）で使えない手順は薄く表示します。「この流れを練習に追加」で、たどった手順の連なりを1つの練習メニューにできます。

フローチャート

手順タブの「⋯」→「フローチャートで見る」で、手順のつながりを図で見られます。箱がコンボパーツ（上の行が始動の状況）、矢印がヒット・ガード・相手の行動などの結果で、結果の次の状況から始まる手順へ引かれます。キャラと始点の状況は上で切り替えます（手順タブで状況を選んでいると、その状況が始点になります）。点線の枠は「出口」です。赤い「未設定」は次の状況がまだ入っていない結果で、押すと次の状況を選べます（そこから始まる手順の数も出ます）。灰色の枠は、次の状況はあるのに、そこから始まる手順がまだない結果です。箱を押すと、下に手順の内容と、前（この手順に繋がる手順）・結果の一覧が出ます。前後の手順の名前を押すとそのステップへ移れ、結果の行の「続きを選ぶ／続きを足す」と、灰色の枠（次の状況はあるが続きのパーツがない出口）は、その状況から始めるパーツを選ぶ画面を開きます。上の「＋新しいパーツを追加」で追加画面へ、下の一覧から既存のパーツを選ぶと、その状況が始動に足されます。フロー上部の「＋パーツを追加」は、選んでいる始点の状況から始まるパーツを追加します（パーツが1つもないときもここから作れます）。同じ手順から同じ手順へ向かう複数の結果（暴れ・バクステなど）は、1本の矢印にまとめ、結果名を矢印の上に1行ずつ並べます（4つ以上は「他N件」で、全部は矢印にカーソルを合わせると出ます）。矢印は、結果の次の状況を始動に選んでいるパーツへだけ引かれます（有利Fが近いだけでは引きません）。↻ が付いた箱は、結果をたどると自分に戻ります。前の手順へ戻るつながり（A→B→A など）は、矢印で図を横切らせず、戻り先を示す「結果 ↩ 手順名」の小さな枠にします。押すと戻り先の手順へ移ります。箱の右上の「−」を押すと、その箱より先の分岐（ほかの道では辿れないパーツと出口）を隠し、箱は破線で「+3」のように隠れた数を表示します（押すと開きます。上の「すべて展開」でまとめて戻せます）。上の「未設定を隠す」は、次の状況が未設定の出口（赤い枠）だけを隠します。

フレーム

キャラごとの技のフレームを、カプコン公式のフレームデータから登録して表示します。技名（カタカナ・ひらがなどちらでも）やコマンド（例：623）で絞り込めます。

「-4F以下」「-6F以下」でガード時の不利を絞り込めます。「ガード不利の大きい順」は、-46F、-42F、…の順です。不明な数値は最後に並びます。

手順タブの「条件」で相手キャラとガードした技を選ぶと、「相手の不利F」が自動で入り、発生がその数値以内のコンボが並びます。ガード時の数値に幅がある技は、不利が小さい側で絞ります。不明・五分・有利の技は自動選択できません。不利Fは直接入力もでき、入力すると技の選択は外れます。距離や押し戻しによって届かない場合があるため、トレモで確認してください。

列
発生・ガード・ヒットは公式の値です。Dはダウンです。行を押すと持続・硬直・キャンセル・ダメージと備考が出ます。
カウンター・パニカン
公式の表に列がないため、ヒット時の値にカウンターは+2F、パニッシュカウンターは+4Fして表示します。ダウン（D）の技は計算しません。※の付いた値は、備考にある技ごとの性能（例：パニッシュカウンター時+13F、膝崩れ）を優先したもので、「地上のみ」などの適用条件も添えます。スマホでは個別性能を技名の下に表示するので、行を開かずに条件を確認できます。
確反の色
ガード時に-4〜-5Fの技はクリムゾン、-6F以下は太字のクリムゾンです。距離や押し戻しで取れない場合があります。ガード-4F以下の技は「確反コンボを探す」から、相手の不利Fを入れた状態で手順タブ（コンボ）を開けます。
データの版と登録
上に、データの版（公式に版の表記がないときは確認した日）と公式ページへのリンクが出ます。登録やパッチ後の入れ替えは、依頼を受けたClaudeが公式ページを読み、キャラごとに入れ替えます。

習得度と練習

習得度は未練習・練習中・ランダムで10連続・実戦で出せるの4段階です。カードのバーを押すと変わり、今の段階をもう一度押すと1段下がります。

練習メニューには、コンボか起き攻め（ルートから作ると手順の連なり）と、トレモの設定（ガード・カウンター・受け身・無敵技の録画再生）を保存できます。メニューの状態は「進行中／完了」です。進行中のメニューに含まれる手順には「練習メニューにあり」と表示し、習得度とは別に管理します。記録には回数・成功に加えて最高の連続成功を入れます。10回連続を記録すると、習得度を「ランダムで10連続」に上げるボタンが出て、練習の手順のうち習得度が2段階目までのものをまとめて上げます。成功率は直近5回の記録の合計です。
